# Ikhmal Fahmi — Mock Portfolio

A bold, creative one-page portfolio built with React + Vite for Ikhmal Fahmi, a software engineering student looking for his first internship.

## Run it

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

The optimized site is written to `dist/`.

## What's inside

- Oversized, responsive hero typography with a rotating role label
- Sticky navigation with a full-screen mobile menu
- Scroll-reveal animations and a custom cursor on desktop
- Filterable project grid with interactive detail modals
- Education/project timeline, "how I work with others" cards, skills, and a demo contact form
- Responsive layouts down to small phones, with reduced-motion support

All content lives in `src/data.js` — edit that file to update your details, projects, or links.
